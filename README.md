# Calculadora de Perímetro, Área e Combustível

Aplicativo Android desenvolvido em Kotlin como atividade complementar de prova da disciplina de **Desenvolvimento Mobile** — UNIPAR (5º Período).

## Funcionalidades

### Calculadora de Área e Perímetro
- **Quadrado:** calcula área (L²) e perímetro (4 × L)
- **Retângulo:** calcula área (B × A) e perímetro (2 × (B + A))
- Detecta automaticamente se é quadrado ou retângulo com base nos valores inseridos

### Calculadora de Combustível
- Calcula a distância percorrida com base no tempo e velocidade média
- Calcula os litros de combustível necessários para a viagem
- Fórmulas utilizadas:
  - `distância = tempo × velocidade`
  - `litros = distância / média (km/L)`
